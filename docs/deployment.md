# Deployment

## Databricks
1. Import the five Python notebooks.
2. Change `MY_ID`.
3. Run them in order.
4. Verify 120 Bronze towers, 376200 Bronze calls, 372150 Silver calls and 43142 Gold rows.
5. Create a scheduled Databricks Job using `job.json`.

## Snowflake
1. Run `snowflake/01_setup_and_queries.sql`.
2. Upload the single Gold CSV generated by `05_export_gold.py` to `@CAPSTONE_STAGE`.
3. Run `COPY INTO GOLD_TOWER_HOUR`.
4. Run the analysis queries.
5. Run COPY again; the second load should report zero files.

## Streamlit Cloud
1. Push this project to GitHub.
2. Create a Streamlit app with main file `streamlit/app.py`.
3. Set the Python requirements to `streamlit/requirements.txt`.
4. Add the contents of `secrets.toml.example` to Streamlit Secrets with real Snowflake values.
5. Deploy.

Never commit Snowflake passwords or secrets to GitHub.
